        Help
        
      
        
        Does it work without internet?
        
        Yes, after the very first build. That build downloads Pake's parts once, and later builds reuse them from this Mac. Apps made from your own files work offline too. An app made from a web address still needs internet to show that website.
        
      
        
      
        
        Can I use it from my phone?
        
        Choose “Use on phone” on the Mac, then scan the code with your phone's camera and type the 6 digits. The phone has to be on the same Wi-Fi. Builds still run on the Mac, and “Open on Mac” opens the finished app there. The first time, macOS may ask whether node can accept incoming connections. Choose Allow. If the phone can't load the page, open System Settings, then Network, then Firewall, then Options, and set node to allow incoming connections. macOS asks again after every Node.js update.
        
      
        
      
        
        Why does the first build take so long?
        
        Pake compiles a small Rust program for your app. The first time, it downloads and compiles everything it needs, which takes 5 to 10 minutes. Later builds reuse that work and take a few minutes.
        
      
        
      
        
        Where are my apps?
        
        In the builds folder inside web2app, one folder per build. Use “Show in Finder” in the history to jump there. Apps installed in Applications are moved to /Applications.
        
      
        
      
        
        What can I put in custom CSS and JavaScript?
        
        Anything a browser extension could add: hide banners, change fonts, add keyboard shortcuts. web2app saves them as inject.css and inject.js and Pake adds them to every page the app opens.
